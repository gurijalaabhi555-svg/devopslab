# ShopEasy E-Commerce Website

## Technologies
- HTML
- CSS
- JavaScript

## Features
- Responsive design
- Product listing
- Search products
- Category filtering
- Add to cart
- Increase/decrease quantity
- Remove from cart
- Cart total
- Demo checkout

## How to run
1. Extract the ZIP file.
2. Open the `ecommerce_html_css_js` folder.
3. Double-click `index.html`.
4. The website will open in your browser.

No installation is required.
